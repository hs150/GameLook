# 🎮 GameLook

GameLook is a modern single-page gaming website inspired by AAA game promotional pages. It focuses on delivering an immersive browsing experience through interactive animations, responsive design, and engaging visual effects.

## ✨ Features

- 🎮 Browse thousands of games
- 🔍 Powerful search functionality
- 📄 Detailed game information
- ⭐ Game ratings and reviews
- 🖼️ High-quality game artwork
- 📱 Fully responsive design
- ⚡ Fast and modern user interface
- 🌙 Clean and elegant UI

## 🛠 Tech Stack

### Frontend
- React.js
- Tailwind CSS
- JavaScript (ES6+)

### Backend
- Node.js
- Express.js

### APIs
- RAWG Game API *(or update with your API if different)*

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/hs150/GameLook.git
```

Move into the project

```bash
cd GameLook
```

Install dependencies

```bash
npm install
```

Run the project

```bash
npm run dev
```
